# llm-agents


## Installation
If you want to use the project, you can install it as a package by running
```commandline
git clone https://github.com/shiqiangw/llm-agents.git
cd llm-agents
pip install .
```

If you want to contribute to this package, you need to run the following command: 
```commandline
git clone https://github.com/shiqiangw/llm-agents.git
cd llm-agents
uv sync
```

Install Ollama and pull `nomic-embed-text` model for embedding computation used in RAG.
```commandline
ollama pull nomic-embed-text
```

To use local model, also pull 
```commandline
ollama pull gpt-oss:20b
```

The chat model can be configured to use `gpt-oss:120b-cloud`. To use it, get an Ollama API key and pass it in the command line args (see below).



## Agent for NeurIPS 2025 papers

### Setup

#### Get the data 
Download https://neurips.cc/static/virtual/data/neurips-2025-orals-posters.json and put the file in the `./data` folder.
```commandline
wget -O data/neurips-2025-orals-posters.json https://neurips.cc/static/virtual/data/neurips-2025-orals-posters.json
```

#### Setup the database 
You can find a docker compose file to setup a read-to-run neo4j database in `database/`. 
Make sure to adjust the credentials per your requirements. Once that is done you can run: 
```commandline
docker compose -f database/docker-compose.yaml up -d 
```

Wait until the database is ready. 

#### Build the knowledge graph
You can build the knowledge graph per your needs by running the following script: 
```commandline
uv run tools/knowledge_graph/graph_generator.py \
    --input-json-file data/neurips-2025-orals-posters.json \
    --embedding-model nomic-embed-text \
    --ollama-server-url http://localhost:11434 \
    --embedding-gen-batch-size 32 \
    --max-parallel-workers 16 \
    # --limit-num-papers  # Optional
```
**Important note:** Generating the full graph over 6k papers can take several hours. We will soon provide an annotated 
knowledge graph for download to save time. 

#### Importing the knowledge graph to a neo4j database
We provide an importer to move the knowledge graph into a graph database that supports vector-based similarity search. 
```commandline
uv run tools/knowledge_graph/neo4j_db_importer.py \
    --graph-path graphs/knowledge_graph.pkl \
    --neo4j-uri bolt://localhost:7687 \
    --neo4j-username neo4j \
    --neo4j-password <YOUR_PASSWORD> \
    --batch-size 100 \
    --embedding-dimension 768 # This must match the vector dims generated by the embedding model.
```

**Note:** This operation is normally very quick.

#### Optional: In-memory index for similarity search only
Run `uv run build_json_rag.py` to build the vector database for RAG. 


### Agent interactions
Run the following command.

For local model:
```commandline
uv run llm-agents-cli \
    -a http://localhost:11434 \
    -m ollama_chat/gpt-oss:20b \
    -t 0.4 \
    --max-tokens 6000 \
    -c 131072 \
    --max-num-papers 10
```

For Ollama cloud model:
```commandline
uv run llm-agents-cli \
    -a https://ollama.com \
    -k $OLLAMA_API_KEY \
    -m ollama_chat/gpt-oss:120b-cloud \
    -t 0.4 \
    --max-tokens 6000 \
    -c 131072 \
    --max-num-papers 10
```

The backend uses LiteLLM, which allows you to use a variety of LLM inference endpoints. 
Find details on the various providers [here](https://docs.litellm.ai/docs/providers).
